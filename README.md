# Projeto Tailwind

Este projeto foi criado para comparar visualmente um layout desenvolvido com CSS puro e outro feito com Tailwind CSS, deixando explícitas as classes utilitárias usadas no front-end.

## Objetivo

O projeto tem como foco mostrar de forma direta e clara:

- a diferença entre HTML + CSS tradicional e Tailwind;
- a quantidade de classes utilitárias aplicadas no layout;
- a facilidade de criar interfaces modernas com utility classes.

## Como executar localmente

1. Abra o arquivo `index.html` diretamente no navegador, ou
2. Rode um servidor local na pasta do projeto:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Tecnologias utilizadas

- HTML5
- Tailwind CSS via CDN
- Google Fonts

## Observações

Este projeto foi pensado como uma demonstração visual para estudos comparativos, sendo uma versão mais enxuta e direta do layout original, com foco em classes do Tailwind visíveis no código e na interface.
